# Logo del dashboard

Copia aquí el logo oficial **rojo horizontal** con el nombre `logo.svg`:

    cp "logos/d-industrimex/d-industrimex-rojo-horizontal.svg" mail_contact_scraper/static/logo.svg

Si no hay `logo.svg`, el dashboard muestra el nombre "D-industrimex®" en Montserrat.
No edites ni recolorees el logo (ver Sistema de diseño D-Industrimex, sección 01).
